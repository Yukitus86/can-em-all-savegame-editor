# ===== TITLE =====
Can 'Em All Save Editor – Money, Full Skill Tree, Prestige Upgrades & Mails

# ===== DESCRIPTION =====
Free, open-source save editor for Can 'Em All (full game and demo) – for Windows and Linux / Steam Deck. Edit money and day, unlock any skill right in the game's own skill tree, buy permanent prestige upgrades, manage the story mails and change game settings. Automatic backups, single file, English and German.

# SECTION 2 – title:
Download & first start
############################################################################

[h1]Download[/h1]
Get the file for your system from the latest release on GitHub:
[list]
[*][b]Windows:[/b] CanEmAllEditor.exe
[*][b]Linux / Steam Deck:[/b] CanEmAllEditor-linux-x64.tar.gz
[/list]
[url=https://github.com/Yukitus86/can-em-all-savegame-editor/releases/latest]github.com/Yukitus86/can-em-all-savegame-editor/releases/latest[/url]

The full source code is in the same repository, so you can check exactly what the tool does or build it yourself.

[h1]Start[/h1]
[olist]
[*][b]Close Can 'Em All completely.[/b] The editor blocks saving as long as the game is running.
[*]Double-click [b]CanEmAllEditor.exe[/b].
[*]Your save shows up on the left (full game and demo are labelled).
[*]Change what you want in the tabs.
[*]Click [b]Save changes[/b] (bottom right).
[*]Start the game – or use [b]Launch game[/b] in the editor.
[/olist]

[h2]Where is my save?[/h2]
The editor finds it automatically:
[code]Full game: %USERPROFILE%\AppData\LocalLow\LuisDev\Can 'Em All\save.sav
Demo:      %USERPROFILE%\AppData\LocalLow\LuisDev\Can 'Em All Demo\save.sav[/code]

[h2]Language[/h2]
Click the [b]flag[/b] in the top left to switch between English and German – your choice is remembered.

[h2]"Windows protected your PC"?[/h2]
The exe is not code-signed, so Windows SmartScreen may warn you the first time. Click [b]More info → Run anyway[/b].

[h1]Linux & Steam Deck[/h1]
[IMAGE: CEA_09_linux.png]
A real Linux program – no Wine needed. Same tabs and features as the Windows version.
[olist]
[*]Steam Deck: switch to [b]Desktop Mode[/b].
[*]Download [b]CanEmAllEditor-linux-x64.tar.gz[/b] and unpack it.
[*]Close the game, then start [b]CanEmAllEditor[/b] (double-click or [i]./CanEmAllEditor[/i] in a terminal).
[*]If it does not start, make it executable: [i]chmod +x CanEmAllEditor[/i]
[/olist]
The game runs through Proton, so the save sits in the game's Proton folder. The editor finds it by itself – also with Flatpak Steam and in other Steam libraries (second drive, SD card):
[code]~/.local/share/Steam/steamapps/compatdata/5133900/pfx/drive_c/users/steamuser/AppData/LocalLow/LuisDev/Can 'Em All/[/code]

[*][b]Everything[/b] – all skills plus all permanent upgrades
[*][b]Starter pack[/b] – bat, knife, pistol, SMG and the vacuum, nothing beyond
[*][b]Money for all missing skills[/b] – you buy them yourself in the game
[*][b]Max money[/b] and [b]Reset all skills[/b]
[/list]


############################################################################
# SECTION 4 – title:
Skill tree & skill list
############################################################################

[IMAGE: CEA_02_skill-tree.png]

[h1]The game's own skill tree[/h1]
All 252 skills (demo: 231) in the same layout and with the same icons as in the game.
[list]
[*][b]Click[/b] a skill for its description, price, what it requires and what it leads to
[*][b]Double-click[/b] or [b]right-click[/b] to unlock or lock it
[*][b]Unlock whole branch[/b] unlocks everything that leads up to a skill
[*][b]Mouse wheel[/b] zooms, [b]drag[/b] moves the tree
[/list]

[h2]Requirements stay valid[/h2]
When you unlock a skill, the skills it needs are unlocked too. When you lock one, the skills built on it go as well. The save always keeps a purchase order the game accepts.

[IMAGE: CEA_03_skill-list.png]

[h1]Skill list[/h1]
Every skill as a card. Search by name, filter by category (combat, weapons, turrets, factory, vacuum, robots, movement, creatures & shifts, special) or by status, and unlock or lock everything that is shown.

Game settings, backups & raw JSON
############################################################################

[IMAGE: CEA_06_settings.png]

[h1]Game settings[/h1]
Everything in settings.sav: language, mouse / camera sensitivity, field of view, invert Y, head bob, blood and wound color, volumes, window mode, resolution, VSync, anti-aliasing, shadows, reflections, ambient occlusion, bloom, chromatic aberration and quality presets.

[IMAGE: CEA_07_backups.png]

[h1]Backups[/h1]
Before every save the editor copies save.sav and settings.sav into [b]EditorBackups[/b] inside the save folder. In the [b]Backups[/b] tab you can restore any backup, make a manual one or delete old ones.

[IMAGE: CEA_08_raw-json.png]

[h1]Raw JSON[/h1]
For tinkerers: both files as text. Edit them directly, export or import.

# SECTION 8 – title:
FAQ & troubleshooting
############################################################################

[h1]FAQ[/h1]

[b]"Save changes" is greyed out.[/b]
Either nothing was changed yet, or Can 'Em All is still running. Close the game completely.

[b]My changes are gone after starting the game.[/b]
Steam Cloud may have put an older save back. Start the game once, quit, then edit again – or switch Steam Cloud off for the game while you edit.

[b]My save is broken / I want my old state back.[/b]
Backups tab → pick the backup from before your change → [b]Restore[/b].

[b]Does it work with the demo?[/b]
Yes. The demo has its own skill data (231 skills, some of them locked in the demo). Prestige and mails only exist in the full game.

[b]Is it safe?[/b]
The editor only touches your Can 'Em All save folder, makes a backup before every write and keeps the exact file format of the game. The source code is public on GitHub.
